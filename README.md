# Nails By KimMy

Een responsive website in HTML, CSS en vanilla JavaScript voor Nails By KimMy in Almere.

## Bekijken

Open `index.html` in een browser. Voor de beste ondersteuning van lokale media kan de map ook met een statische webserver worden gepubliceerd.

## Inhoud aanpassen

- Prijzen en behandelingen staan centraal in `js/services.js`.
- Galerijfoto's en videobestanden worden geselecteerd in `js/main.js`.
- Openingstijden en contactgegevens staan in `index.html` en `js/main.js`.
- De tijdelijke typografische merkvermelding kan later door een logo-afbeelding worden vervangen.

De galerij gebruikt foto's `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`, `7.jpg`, `8.jpg`, `9.jpg`, `10.jpg` en `11.jpg`. Foto's met een zichtbaar oud adres of oud telefoonnummer zijn bewust niet opgenomen. De zes beschikbare MP4-bestanden zijn beschikbaar in de videosectie.

Een definitieve domeinnaam is nog niet bekend; daarom is geen canonical-URL ingesteld.
